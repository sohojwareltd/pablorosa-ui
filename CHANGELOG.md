# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2024-12-XX

### Added
- Initial release
- Hero section with video background
- Music player with Spotify integration and drawer system
- Gallery with horizontal interlocking grid and lightbox
- Album hero section with audio player
- YouTube sets section
- Tour slider section
- Field journal with masonry layout
- Social hub with newsletter integration
- Contact form section
- Custom cursor effects
- Smooth scrolling with Lenis
- Responsive navigation menu
- Global music player drawer
- Global gallery lightbox
- TypeScript support
- Full responsive design for all screen sizes

### Features
- Cinematic animations with Framer Motion
- Editorial design with refined typography
- System-style music player interface
- Terminal-style UI elements
- Interactive hover effects
- Keyboard navigation support
- Image optimization with Next.js Image
- Code splitting and lazy loading

### Technical
- Next.js 16 with App Router
- Tailwind CSS 4
- React 19
- TypeScript 5
- Framer Motion for animations
- React Icons
- React Intersection Observer
