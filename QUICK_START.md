# Quick Start Guide

Get up and running in 5 minutes!

## Step 1: Install Dependencies

```bash
npm install
```

## Step 2: Start Development Server

```bash
npm run dev
```

## Step 3: Open in Browser

Navigate to: `http://localhost:3000`

## That's It! 🎉

The template is now running locally. You can start customizing:

### Quick Customizations

1. **Update Site Title**
   - Edit `app/layout.tsx` → `metadata.title`

2. **Add Your Music**
   - Edit `components/sections/Music.tsx` → `tracks` array

3. **Add Your Images**
   - Place images in `public/coverart/`
   - Edit `components/sections/Gallery.tsx` → `artworks` array

4. **Update Social Links**
   - Edit `components/sections/SocialHub.tsx` → social media URLs
